# Requirements (frozen)

Shared verbatim by the Ponytail build and the normal Claude Code baseline. Do not edit.

A React + TypeScript single-page todo app.

- **R1** Add a todo from a text input (Enter or button). Text is trimmed; empty or whitespace-only text is rejected.
- **R2** Toggle a todo done / not done.
- **R3** Delete a todo.
- **R4** Accessible: labelled input, a real checkbox per todo labelled by its text, a delete button with an accessible name.
- **R5** Unit tests for the todo logic. `npm test` and `npm run build` both pass.

## Out of scope

Persistence (localStorage), editing, filters, counters, routing, state libraries, UI kits, styling beyond browser defaults, any backend.
